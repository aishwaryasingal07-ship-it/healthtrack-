🎓 How This AI Analyzer Works (Academic Guide)

  1. Data Fetching: Flask queries the SQLite tests table to fetch the latest values and reference bounds.
  2. Prompt Formatting: ai_service.py formats the numbers into a clear markdown-prompt comparing measured values against healthy minimums and maximums.
  3. Groq API Request: The prompt is sent to Groq's high-speed inference engine using the official Python SDK (llama-3.3-70b-versatile).
  4. Safety Alignment: Strict negative system prompts guarantee that the AI never prescribes drugs or diagnoses illnesses, adhering to healthcare ethics.
